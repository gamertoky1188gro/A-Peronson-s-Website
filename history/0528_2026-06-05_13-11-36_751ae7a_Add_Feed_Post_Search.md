## File-by-File Breakdown

- **server/controllers/feedPostController.js** (15 lines) — Added `searchFeedPostsController` handler
- **server/routes/feedRoutes.js** (2 lines) — Added `GET /feed/search` route with `requireAuth`
- **server/services/feedPostService.js** (29 lines) — Added `searchFeedPosts()` function with Prisma query (title/caption/description_markdown contains, cursor pagination)
- **src/pages/SearchResults.jsx** (100 lines) — Added feed posts tab, estimated count display, results rendering with MasonryGrid, hashtags, and date display

## Detailed Diff Analysis

- **Backend**: `searchFeedPosts()` queries `feedPost` table with `status: "published"` and case-insensitive `contains` search on `title`, `description_markdown`, and `caption`. Uses cursor-based pagination with `skip`/`take`.
- **Frontend**: Added `fileText` icon, feedPosts state, `filteredFeedPosts` derived state, pulls feed data alongside requests/products in the main search and loadMore functions, renders results in a MasonryGrid with title, description, hashtags, and date. Shows estimated count in the results header.
