Removes `MAX_AI_ANSWER_CHARS` and the `sanitizeString` length cap from all AI provider return paths (opencode, Ollama, OpenRouter, Gemini). All responses now return full text without truncation.

## Detailed Diff Analysis
Removes the `MAX_AI_ANSWER_CHARS` constant (was 8000 after 0428) and strips `sanitizeString(text, MAX_AI_ANSWER_CHARS)` wrapping from:
- `callOllamaChat`
- `callOllamaCompletion`
- `callOpenRouter`
- `callGemini`
- `callOpencode`
- `streamOpencodeReply`

Each now returns `unescapeHtml(text || "")` directly.

## Why This Change
The truncation was arbitrarily capping AI responses. With improvements from 0428 (preferring blocking results), the full answer is reliably available.

## Was It Useful
Yes — removes an artificial limit. Users can now receive long-form AI responses.

## Impact Analysis
**Medium.** Long responses may increase bandwidth/computation but improve UX.
