## Detailed Diff Analysis

### `linkPreviewService.js`
- Custom HTML fetcher with timeout (5s), size limit (256KB), and User-Agent header.
- Extracts OG meta tags (title, description, image, site_name) and favicon via regex.
- Caches results in Prisma with 24h TTL.
- `batchGetLinkPreviews()` fetches missing/stale previews in parallel.

### `LinkPreviewCard.jsx`
- Card component showing OG image, domain, title, and description with fallback handling.
- Image error handling with `onError` fallback.

### `FeedItemCard.jsx`
- Replaced plain URL `<a>` links with `LinkPreviewCard` components using `item.link_previews` data.

### Server-side
- New `/api/link-preview/preview` endpoint.
- Feed post service enriches posts with link previews during search and feed loading.
