## Key Changes

### Security Hardening
- **Helmet CSP**: Added `helmet()` to Express app for secure HTTP headers
- **WebSocket origin validation**: `verifyClient` callback checks `ALLOWED_WS_ORIGINS` env var against client origin
- **SSRF protection in Python AI**: URL checking now blocks private/internal IPs (169.254.x, 127.0.0.1, 10.x, 172.16-31.x, 192.168.x) and restricts to HTTPS only
- **Auth bug fix**: `validateRole` → `validatePublicRole` in auth controller — previously the public signup endpoint would accept `admin` as a valid role
- **New user default**: `verified: false` instead of `verified: payload.role === "admin"`
- **Admin security**: Removed `ADMIN_EXEC_ALLOW_ANY` bypass
- **JWT hardening**: `JWT_SECRET` is now required (exits if missing), no fallback to `"mvp-dev-secret"`

### Infrastructure
- **Syslog server** (`server/services/syslogServer.js`): TLS-based RFC 5424 syslog receiver on port 6514 with auto-generated self-signed cert, daily log rotation
- **Nginx reverse proxy** (`docker/nginx.conf`): HTTP→HTTPS redirect, proxy to app on port 4000, WebSocket support with 60m read timeout
- **docker-compose.yml**: Added nginx service, hardened db/opensearch ports to 127.0.0.1 only, secrets via env vars
- **OpenSearch in CI**: Auto-start via Docker in run scripts, healthcheck fix (HTTP instead of HTTPS, removed security plugin disable)

### AI Moderation Refactoring
- `aiModerationService.js`: Major rewrite — uses `python3 -c` inline script instead of temp files, `crypto.randomUUID()` for temp filenames, common `runPython` helper, safer JSON escaping
- `hasShellInjection` simplified (already fixed in 0383)
- `OPENSEARCH_URL`/credentials now read from env vars as fallback in `openSearchService.js`

### Audit Trail Migration
- `auditStore.js`: Switched from `admin_audit.json` file to Prisma `adminAudit` table. No more hash chain. `sanitizeAuditPayload` uses a `Set` for faster redaction

### CI Pipeline
- `scripts/run.sh --mode=ci`: Full pipeline — start OpenSearch → reindex → lint → test → smoke
- GitHub Actions permissions: `contents: read` added to all workflows
- OpenSearch CI workflow uses `${{ secrets.OPENSEARCH_PASSWORD }}` instead of hardcoded password

### Dependency Changes
- `vite`: downgraded from `^8.0.0-beta.13` to `^6.3.2` (stable), removed overrides
- `@fortawesome/fontawesome-free`: pinned to `^6.7.2` (was `^7.2.0`)
- Removed `babel-plugin-react-compiler`, `rtf.js`, `webodf`
- Added `helmet: ^8.1.0`
- `babel-plugin-react-compiler` removed from vite config
- `@testing-library/dom` moved from `dependencies` to `devDependencies`

### Other
- `render.yaml`: Added OpenSearch env vars, build command includes `./scripts/run.sh --mode=ci`
- `usePageMeta.js`: BASE_URL changed from `gartexhub.com` to `gartexhub.onrender.com`
- `rateLimiter.js`: Added periodic cleanup of stale IP entries (every 5 min)
- Windows run scripts: Added OpenSearch Docker auto-start
