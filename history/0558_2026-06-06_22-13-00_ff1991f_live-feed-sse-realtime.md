## High-Level Summary

Adds Server-Sent Events (SSE) for real-time feed updates. When posts are created, updated, or deleted, the server pushes events to connected clients via a new `/api/feed/stream` endpoint. The client subscribes via `EventSource` and updates the feed in-place.

## Detailed Diff Analysis

### `feedStreamController.js`

- JWT-authenticated SSE endpoint.
- Sends `new_post`, `updated_post`, `deleted_post` events.
- 30s keepalive interval.

### `realtimeBus.js`

- Added 3 new event types: `feedPostCreated`, `feedPostUpdated`, `feedPostDeleted`.
- Increased max listeners from 50 to 100.
- New emit helper functions for each event.

### `feedPostService.js`

- `createFeedPost`, `updateFeedPost`, `deleteFeedPost` now emit realtime events with enriched post data (author name, avatar).

### `feedRoutes.js`

- Added `/api/feed/stream` route (no auth middleware, auth is handled via JWT token in query param).

### `feedRealtime.js`

- Client-side helper: creates `EventSource` with auth token, dispatches to callbacks.

### `MainFeed.jsx`

- `useEffect` to subscribe on mount, unsubscribe on unmount.
- New posts prepended, updated posts replaced, deleted posts removed from state.
