## Custom Title

Add EU Country Mapping and Buyer Region-Country Validation

## High-Level Summary

Introduces a shared EU country mapping module and validates buyer geography during verification. When a buyer selects an EU country, the region is automatically set to EU and EU-specific document requirements are activated. The Verification Center now shows a buyer country dropdown and conditionally displays EU documentation guidance.

## File-by-File Breakdown

- **server/controllers/verificationController.js** (+8/-2): Added error handling with status codes.
- **server/services/verificationService.js** (+27/-0): Added `validateBuyerGeography` function cross-referencing buyer country with EU set.
- **shared/config/geo.js** (+35): New shared config with EU_COUNTRIES list and `isEuCountry` helper.
- **src/pages/VerificationCenter.jsx** (+104/-21): Added buyer country dropdown, automatic region mapping, EU-specific document guidance banner.

## Detailed Diff Analysis

The `geo.js` module defines 27 EU countries and exports `isEuCountry()`. The verification service validates that if a buyer country is in the EU, the buyer region must be `EU`, and vice versa. The Verification Center now shows a buyer country select (only for buyer role) populated from EU_COUNTRIES, automatically maps to `buyer_region`, and displays EU-specific document requirements and credibility guidance.
