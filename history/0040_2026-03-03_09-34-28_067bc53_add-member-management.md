## High-Level Summary
Introduces a complete member management system with CRUD APIs for organization sub-accounts. The backend supports creating members with role/permission assignment, password reset, deactivation, and removal. The MemberManagement page is rewritten from a static mock to a fully functional CRUD interface with search, create modal, permission editing, and password reset.

## Detailed Diff Analysis
The member service enforces plan-based limits: free plans get max 10 active members. Permissions are validated against a whitelist (`view_requests`, `assign_requests`, `manage_members`, `reports_only`) with conflict detection. Passwords are bcrypt-hashed. The frontend has a reusable Modal component and PermissionEditor sub-component. Actions include create, edit permissions, reset password (returns temporary password), deactivate, and remove.
