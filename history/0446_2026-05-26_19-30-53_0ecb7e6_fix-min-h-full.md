## High-Level Summary

Replaces `min-h-screen` with `min-h-full` on the AgentDashboard's outer div and flex container so the page fills only the remaining layout height instead of the full viewport, preventing double-scrollbar issues when combined with the AppLayout.

```diff
-   <div className="mx-auto flex min-h-screen max-w-[1600px] flex-col lg:flex-row">
+ <div className="min-h-full bg-[radial-gradient...]">
+   <div className="mx-auto flex min-h-full max-w-[1600px] flex-col lg:flex-row">
```

## Why This Change

`min-h-screen` makes the element as tall as the viewport, which creates an extra scrollbar when the page is already inside a full-height layout wrapper. `min-h-full` respects the parent's height constraints.

Yes — fixes double-scrollbar UX issue.
