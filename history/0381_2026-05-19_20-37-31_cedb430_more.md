## High-Level Summary

Massive refactoring commit that introduces a Redux-backed `ThemeProvider` context to centralize theme management across the entire frontend. Previously, dozens of components managed their own dark/light theme state via `useState`, `useEffect`, and localStorage — often with redundant polling and event listeners. This commit removes all that boilerplate and replaces it with a single `useTheme()` hook backed by Redux. Additionally, adds `isLoggedIn` awareness to Pricing and TexHub landing pages to redirect authenticated users to `/feed` instead of `/signup`. On the backend, updates the `.env` with new database and AI configuration strings, updates `server.js` with streaming AI reply infrastructure via `opencode`, adds `rateLimiter`, updates `infraService`, and deletes the bloated `package-lock.json`.

## Detailed Changes

### `.env`

- Updated `DATABASE_URL` to new Aiven PostgreSQL connection string with `connection_limit=5`
- Added ADMIN_DEVICE_ALLOWLIST and related admin configuration variables
- Added OpenSearch configuration (URL, username, password)
- Added AI configuration: `AI_ENABLED=true`, `AI_PRIMARY_PROVIDER=opencode`, `AI_FALLBACK_PROVIDER=gemini`
- Added `OPENCODE_*` and `GEMINI_*` environment variables
- Added AI threshold settings

### `src/lib/ThemeProvider.jsx` [NEW]

A React context provider that wraps the Redux theme slice. Exposes `theme`, `setTheme`, and `toggleTheme` via the `useTheme` hook. Listens for `storage` events to sync across tabs.

### Theme Refactoring Across All Components

Every page that previously managed its own theme state now imports `useTheme` from `../lib/ThemeProvider` and delegates all theme toggling to the centralized context. Removed:

- Local `useState` for `theme`/`darkMode`/`dark`
- `useEffect` listeners for `theme-change` custom events
- `useEffect` polling for localStorage changes
- Manual `document.documentElement.classList` toggling
- Manual `localStorage.setItem` calls

### `src/pages/Pricing.jsx`

- Added `isLoggedIn` check using `getToken()`
- Changed CTA buttons conditionally: logged-in users see "Go to Dashboard" instead of "Create your organization"
