## Custom Title

Add LLM Integration with Qwen2.5-0.5B Model Config and RAG Pipeline

## High-Level Summary

Comprehensive rewrite of `assistantService.js` adding local LLM integration. Introduced `smallTalkRules`, `compactTokenKey`, `buildKnowledgeContext`, `buildAgentPrompt`, and `generateDynamicAnswer` functions. The service now uses an OpenAI-compatible API endpoint (defaulting to llama.cpp at `http://127.0.0.1:8080/v1/chat/completions`) with the `Qwen2.5-0.5B-Instruct-Q4_K_M.gguf` model. The `assistantReply` follows a three-tier flow: knowledge base match → AI generation with code/knowledge context → agent forwarding.

## File-by-File Breakdown

- **server/services/assistantService.js** (+313/-48 lines): Complete refactor adding LLM integration, small talk rules, improved keyword matching with `compactTokenKey`, RAG pipeline via `buildKnowledgeContext` and `buildAgentPrompt`, and `generateDynamicAnswer` using `fetch()` with AbortController timeout.

## Detailed Diff Analysis

### New Constants

- `LOCAL_LLM_ENDPOINT`, `LOCAL_LLM_MODEL` (Qwen2.5-0.5B), `LOCAL_LLM_TIMEOUT_MS` (12s), `MAX_AI_ANSWER_CHARS` (700), `MAX_KNOWLEDGE_CONTEXT_CHARS` (1200).

### New Functions

- `compactTokenKey`: Aggressive normalization removing all non-alphanumeric characters.
- `findBestKeywordRule`: Enhanced keyword scoring using compact token sets.
- `buildKnowledgeContext`: Collects top-3 matching knowledge entries and global/smalltalk rules into a context string.
- `buildAgentPrompt`: Assembles a system prompt with knowledge context, code context, and user question.
- `generateDynamicAnswer`: Calls the LLM endpoint via `fetch()` with AbortController (12s timeout), returns null on failure.
- `searchCodeContext`, `collectCodeFiles`, `getCodeFiles`, `findBestSnippet`: Same recursive code-context retrieval as commit 0098.

### Updated `assistantReply` Flow

1. Try knowledge base match (FAQ/fact)
2. If no match, try `generateDynamicAnswer` with knowledge + code context
3. If LLM fails, return `forward_to_agent: true` with metadata

## Why This Change May Have Been Needed

To enable offline/local AI assistant capability using a small LLM model (0.5B parameters) that can run on consumer hardware via llama.cpp.
