## Detailed Changes

### `src/lib/usePageMeta.js` [NEW — 272 lines]
A comprehensive SEO/meta hook supporting:
- **Open Graph**: `og:title`, `og:type`, `og:description`, `og:url`, `og:image`, `og:locale`, `og:site_name`, `og:determiner`, `og:audio`, `og:video`
- **Twitter Card**: `twitter:card`, `twitter:site`, `twitter:creator`, `twitter:title`, `twitter:description`, `twitter:image`
- **Structured types**: `article`, `book`, `profile`, `music`, `video`, `payment` — each with full sub-property support
- `fb:app_id`
- **Cleanup**: On unmount/update, removes all previously set meta tags and restores document title
- All URLs are made absolute using `BASE_URL = "https://gartexhub.com"`
- Uses a `registry` object to track created elements for proper cleanup

### `src/lib/ThemeProvider.jsx`
Added: When theme changes, also updates or creates a `<meta name="theme-color">` tag with value `#0f172a` (dark) or `#f8fafc` (light).

### Pages using `usePageMeta`:
| Page | Title | Description |
|------|-------|-------------|

| Pricing | "Pricing — GarTexHub" | Choose the right plan |

| Login | "Login — GarTexHub" | Sign in to manage sourcing, products, connections |
| Signup | "Create Account — GarTexHub" | Join as buyer, factory, or buying house |

### `src/App.jsx` & `src/components/NavBar.jsx`
Removed lazy import and route for `/mvp` (MvpDashboard). Removed "MVP" link from public links in NavBar.
