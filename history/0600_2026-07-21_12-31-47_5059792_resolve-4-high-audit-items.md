### Core changes

**Fix 6: Console statements → Centralized logger**
Replaced 50+ bare `console.warn()`/`console.error()` calls across 22 files with `logger.warn()`/`logger.error()`. The `logger.js` utility gates all output behind `import.meta.env.DEV`, meaning no console statements reach production. Files migrated: `auth.js`, `AdminGovernance.jsx`, `AdminPanel.jsx`, `BuyerProfile.jsx`, `BuyerRequestManagement.jsx`, `BuyingHouseProfile.jsx`, `CallInterface.jsx`, `ContractVault.jsx`, `FactoryProfile.jsx`, `FeedItemCard.jsx`, `FloatingAssistant.jsx`, `Insights.jsx`, `MainFeed.jsx`, `NotificationsCenter.jsx`, `OnboardingPage.jsx`, `OnboardingWizard.jsx`, `OrgSettings.jsx`, `ProductManagement.jsx`, `ProfilePage.jsx`, `RatingFeedback.jsx`, `SearchResults.jsx`, `SupportReports.jsx`, `AdminAISection.jsx`, `FileExplorerSection.jsx`.

**Fix 7: Admin credentials in localStorage → secureStorage**
Replaced all `localStorage.getItem/setItem` calls for admin credentials (`admin_mfa_code`, `admin_device_id`, `admin_passkey`, `admin_stepup_code`) with `secureStorage.getItem/setItem` in `AdminPanel.jsx`. The new `secureStorage.js` stores values in `sessionStorage` with a 60-minute TTL and automatic expiry.

**Fix 5: SSE token in URL → Authorization header**
Completely rewrote `feedRealtime.js` — replaced `EventSource` (which cannot set custom headers) with `fetch` + streaming `ReadableStream` + `Authorization: Bearer <token>` header. The new implementation includes exponential backoff reconnection (3s → 30s max), AbortController support, and proper line-based SSE event parsing.

**Fix 6b: Input validation + XSS in SearchResults**
- Added `DOMPurify` dependency to `package.json` and imported it in `SearchResults.jsx`
- The `highlightText()` function now sanitizes input with `DOMPurify.sanitize(text, { ALLOWED_TAGS: [] })` before regex replacement, preventing XSS via search query injection

**Additional fixes in AdminPanel.jsx:**
- `resetPassword()`: replaced empty `newPassword` variable with `window.prompt()` + 8-char minimum validation
- `saveEmailConfig()`: added `isValidEmail()` regex validation for `from_email` and `test_recipient`
- `sendEmailTest()`: added recipient validation before sending
- Rejection/dispute resolution: replaced empty string initializers (`"" || "rejected_by_admin"`) with literal defaults

**ContractVault.jsx null safety:**
- `mapContract()`: added `if (!c) return null` guard at the top
- `loadContracts()`: added `.filter(Boolean)` after `.map(mapContract)` to remove nulls
- All `console.warn`/`console.error` → `logger.warn`/`logger.error`

## Why This Change Was Needed

Four HIGH-priority audit items remained open after the initial audit (Jul 19). This commit resolves them systematically:
1. Console statements in production expose implementation details and can leak data → wrapped behind `logger` that's dev-only
2. Admin credentials in `localStorage` persist indefinitely and are accessible to any JS → moved to `sessionStorage` with TTL
3. SSE tokens in URL query params are logged by servers, proxies, and browser history → moved to `Authorization` header
4. Search highlight rendering used raw user input → now sanitized with DOMPurify
In addition, `ContractVault.jsx` null safety was partially addressed, and `AdminPanel.jsx` received input validation patches.
