## Detailed Diff Analysis

- **Spelling suggestions**: Uses Levenshtein distance (≤ 2) between query and product/requirement titles to suggest corrections
- **Search history**: Logged as `eventLog` entries with type `search_run`, retrievable via `/api/search/history`
- **Certifications filter**: Both product and requirement controllers now filter by `hasSome` on certification arrays
- **Date range**: `postedAfter`/`postedBefore` query params mapped to `created_at.gte`/`.lte`
- **Location radius**: `distanceKm` + `locationLat`/`locationLng` — coarse filtering via ±offset on lat/lng (1° ≈ 111km)
- **Frontend**: The SearchResults.jsx grew by 348 lines adding all these UI controls
