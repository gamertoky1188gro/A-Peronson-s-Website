## Detailed Changes

### `public/manifest.json` [NEW]
PWA web app manifest for "GarTexHub" with:
- Name, short_name, description, theme/background colors (`#0f172a`)
- `display: standalone`, orientation, scope
- SVG icon reference
- 8 shortcuts (Home, Pricing, About, Help, Login, Sign Up, Terms, Privacy)

### `index.html`
Added `<link rel="manifest" href="/manifest.json" />`

### `src/components/NavBar.jsx` — Major Enhancements
- **`useSmartHover` hook**: Implements trajectory-aware hover with configurable `ENTER_DELAY` (180ms) and `EXIT_DELAY` (250ms). Samples pointer movement (`TRAJECTORY_SAMPLE=4`) to determine intent direction — if the pointer is heading toward the dropdown, it opens immediately; otherwise it uses the delayed enter.
- **Invisible buffer zone**: A 16px tall invisible `div` between trigger and dropdown to prevent accidental closing.
- **Mobile back button**: Added a chevron-left back button on mobile (`md:hidden`) that calls `navigate(-1)`.
- **Dropdown logic rewritten**: Uses `show` (combines `isOpen || hover.intent`) instead of just `isOpen`. Separated `handleTriggerEnter`, `handleTriggerLeave`, `handleDropdownEnter`, `handleDropdownLeave`.
- **Dropdown close timeout**: Reduced from 3000ms to 600ms.
- **"My Profile" nav item** added at the top of the Core group with its own icon (`Vote`).
- **"Manage Feed" → "Manage Listings"** label change across all user roles.
- **Active route detection**: Now checks `location.pathname + "?" + location.search` in addition to plain `location.pathname`.
- Icon mapping added for "My Profile" and "Manage Listings".

### `src/pages/OrgSettings.jsx`
- Added **Theme tab**: Three-style selector (Light/Dark/System) with `Sun`/`Moon`/System SVG icons using the centralized `setTheme` from `useTheme`.
- Added **Privacy tab**: Profile visibility controls (search engine indexing checkbox), data & sharing toggles (show email, show phone, activity status).
- Added **Account Lock section** in Security tab: UI for temporarily freezing account with explanatory amber warning card.
- Imported `Sun`, `Moon` from lucide-react.

### `src/pages/MainFeed.jsx`
- Changed quick-action labels: "Manage Feed Posts" → "Create Listing" for all roles, "Post a Product" → "Create Listing".

### `src/pages/TexHub.jsx`
- Light mode styling improvements: changed dark-themed cards (`from-slate-900 to-sky-900`) to light variants (`from-sky-50 to-white`) with proper text colors.
- Light mode Pill component: changed from `bg-slate-800` to `bg-slate-100`.
- Light mode buttons: Browse Suppliers and Login buttons now use `bg-slate-100`/`text-slate-700` in light mode.
